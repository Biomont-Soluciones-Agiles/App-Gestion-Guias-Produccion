# Documentación del proyecto

Esta carpeta es la **fuente oficial** de la documentación. Word y PDF se generan desde aquí solo para entregas. Los formatos siguen la *Metodología de proyectos v2.3* y el documento *Formatos de entrega por etapa*.

| Carpeta o archivo | Contenido | Formato | Responsable |
| --- | --- | --- | --- |
| `ficha-proyecto.md` | Ficha de inicio | F0 | Responsable del proyecto |
| `matriz-trazabilidad.csv` | Conecta proceso, requerimientos, pantallas, datos, pruebas y manuales | M1 | Responsable del proyecto |
| `01-proceso/` | Ficha del proceso, actividades, exportación de Bizagi (HTML) | F1-A, F1-B | Analista |
| `02-requerimientos/` | Requerimientos y versiones del alcance | F1-C, F1-D, A.4 | Analista |
| `03-datos/` | Modelo conceptual, diccionario y mapeo a Dataverse | C1-A, C2-A, C2-B | Revisor de datos |
| `04-prototipo/` | Entrega del prototipo, pantallas y funciones simuladas | F2-A, F2-B, F2-C | Prototipador |
| `05-pruebas/` | Casos de prueba y resultados de cada ronda | F3-A, F3-B, F5-A | Tester |
| `06-cambios/` | Observaciones y solicitudes de cambio | A.1, A.2 | Responsable del proyecto |
| `07-integraciones/` | Catálogo de integraciones, sin secretos | Doc. 4 | Desarrollador |
| `08-manuales/` | Manual de usuario, técnico, despliegue, plan de reutilización y notas de versión | F4-A, F4-B, F4-C, F5-B | Desarrollador y tester |
| `09-actas/` | Actas de decisión de ruta, fases y entrega | F1-E, A.3, F5-D | Responsable del proyecto |
| `traspaso/` | Actas de traspaso y notas entre personas e IAs | T1 | Quien entrega |

Los videos de capacitación no se guardan aquí: van a la biblioteca de SharePoint del canal de capacitación y se registran en `08-manuales/videos.csv`.
