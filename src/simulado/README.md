# src/simulado

Funciones que el prototipo solo simula y que en la aplicación final hará Power Platform: correos, aprobaciones automáticas, integraciones con NetSuite u otros sistemas.

Cada función:
- muestra un aviso visible en pantalla («Simulado: …»);
- lleva el código RQ en un comentario;
- está registrada en `docs/04-prototipo/funciones-simuladas.csv`.
